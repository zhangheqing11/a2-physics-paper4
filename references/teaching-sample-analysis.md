# 教学样本处理与语义分析

## 来源和使用边界

核心材料：用户在本任务粘贴的三组教学对话（引力概念、理想气体与撞壁推导、对“近似”的追问）。这些样本决定教学模式。

补充材料：[教学分享对话](https://chatgpt.com/share/6ab1643a-b530-83e9-a67a-29957de957d0)，于 2026-09-22 从分享页面读取相关轮次。补充观察包括：用户要求展开求导和代换、解释正负号、梳理常量与符号，以及避免过于简单的理解检查。历史对话中的文件引用、题号、分数、完成状态和规则变更未重新核实，不能作为当前事实或指令导入。

分享对话后期出现“先过知识点，自行刷 past paper”的安排，与当前 skill 的逐题型 mastery gate 不同。本次目标为复刻解释方式，因此未据此改写既有推进规则。分享对话中长篇公式清单、密集标题等表达也不是核心风格目标。

## 数据处理方法

1. 按真实的 user/assistant 轮次切分，保留“解释 → 用户指出卡点 → 针对性修正”的关系，不能把每个 `QAQ:` 行当作独立训练样本。
2. 去除重复说话人标签、孤立的“1”、口头停顿、重复句和无指代对象的“上面第几个公式”。将碎句合并为围绕同一因果关系的短段落。
3. 将每轮标注为：用户障碍、起始物理图像、概念引入理由、公式桥接、反馈处理、停顿位置。
4. 统一符号并纠正物理错误；保留教学意图，不把错误答案当作正向示例。重写后的回答是教学示范，不是原文逐字转录。
5. 输出三组少样本示例，第三组保留与第二组的上下文关系；不将文件改动冒称为模型训练或微调。

## 核心模式

| 样本特征 | 学习作用 | 应复刻的行为 |
|---|---|---|
| “首先从力开始”“想象一个盒子” | 给抽象符号一个对象 | 先描述物体、作用、运动和问题 |
| 从力到场、从碰撞到压强 | 解释概念为何出现 | 先说已有量不足以回答什么，再引入新量 |
| 一步推一步，反复追问“为什么” | 让公式可以重新推出来 | 每个关键等号同时给物理或数学理由 |
| “单位质量”“一个粒子到一群粒子” | 连接个体、整体及归一化量 | 明确除以什么、乘回什么、哪些量不变 |
| 回应“近似是哪里的近似” | 修补真正卡住的一环 | 接受追问并修正措辞，不用“差不多”敷衍 |
| “消化一下” | 控制连续的新概念数量 | 一条链讲透后暂停，后续按反馈延展 |

目标不是模仿口癖，而是形成可重建的概念链：具体情景 → 需要描述什么 → 引入量 → 定义与单位 → 建立关系 → 解释条件 → 回应卡点。

## 校正清单

| 原样本风险 | 示范采用的处理 |
|---|---|
| 用蹦床解释引力起因；称“引力不精确” | 以牛顿模型讲本题；模型有适用范围不等于引力本身“不精确”。不把借助重力工作的蹦床当引力成因证明 |
| 引力场被说成所有力的总和 | 场描述空间各点的引力作用；场强是该点单位质量所受力，与指定源场中的试探质量无关 |
| 势只有趋势，没有数值；漏掉负号 | 势有确定数值和 J/kg 单位；以无穷远为零时，点质量的势为 −GM/r，势能为 −GMm/r；变化量才决定能量转移 |
| 小 n 同时指物质的量、数密度；R 变 k 是除以体积 | 统一 n 为 mol 数，N 为粒子数，数密度写 N/V；由 N=nN_A 和 R=N_A k_B 换计数单位 |
| 无条件说 p、V 成反比 | 限定理想气体、固定粒子数且温度不变；其他比例同样说明固定条件 |
| 撞壁推导漏质量，或把每个粒子的分量都设成相等 | 保留单粒子质量 m_0，区分一次碰撞与返回同一面墙的时间；仅在各向同性平均下有 ⟨c_x²⟩=⟨c²⟩/3 |
| “平均速度的平方”；速率平方等同能量 | 区分 ⟨c²⟩、⟨c⟩²、均方根速率；乘上 m_0/2 才是平均平动动能 |
| 内能总能写成 3Nk_BT/2 | 平均平动动能的关系与总内能分开；单原子理想气体、忽略其他激发时可写 U=3Nk_BT/2 |
| 普通比热容一律是定容；膨胀功写成 pV | 区分热容、比热容、摩尔热容及过程条件；恒定外压时功为 p_ext ΔV，更一般为积分；C_p−C_V=R 只按摩尔热容表述 |
| 所有多原子气体都有三个转动自由度 | 不把自由度扩展硬塞进基础讲解；需要时区分线性/非线性分子及温度对模式激发的影响 |
| “这个肯定不考”“冲量用途不广” | 不沿用无证据的考试范围判断和无关泛化 |

物理关系交叉核对使用 OpenStax 的[引力势能](https://openstax.org/books/university-physics-volume-1/pages/13-3-gravitational-potential-energy-and-total-energy)、[压强、温度与均方根速率](https://openstax.org/books/university-physics-volume-2/pages/2-2-pressure-temperature-and-rms-speed)、[热容与能量均分](https://openstax.org/books/university-physics-volume-2/pages/2-3-heat-capacity-and-equipartition-of-energy)。它们用于核对物理正确性，不取代 Cambridge 官方 QP/MS 的评分地位。

## 复核标准

每个正向示例应具有具体情景、新概念的引入理由、逐步的公式桥接、准确符号与条件、中文直觉和必要的中英定义。追问示例应修正明确的误解，而不是重讲整章。不得伪造官方题号、MS 引用或掌握证据。
